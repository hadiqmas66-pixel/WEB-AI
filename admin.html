Panduan Menghubungkan ke Database MySQL

Sesuai permintaan Anda, antarmuka admin panel ini saat ini berjalan dalam mode simulasi aktif (data tersimpan di browser via localStorage sehingga Anda bisa langsung menguji edit nama, harga, stok, dan gambar).

1. Skema SQL untuk Database Anda (MySQL)

Jalankan query SQL berikut di database evenue (atau nama database MySQL Anda):

CREATE TABLE IF NOT EXISTS products ( id VARCHAR(50) PRIMARY KEY, name VARCHAR(255) NOT NULL, category VARCHAR(50) NOT NULL, price_usd DECIMAL(10, 2) NOT NULL DEFAULT 0.00, price_idr VARCHAR(50) NOT NULL, stock INT NOT NULL DEFAULT 0, image VARCHAR(255) NOT NULL, badge VARCHAR(100) NULL, short_desc TEXT NULL, rating DECIMAL(3, 1) DEFAULT 4.8, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP );

2. Endpoint API di server.js

Kami sudah menyiapkan kerangka route di file server.js untuk endpoint:

  • GET /api/admin/products — Mengambil daftar seluruh produk
  • PUT /api/admin/products/:id — Memperbarui nama, harga, stok, gambar
  • POST /api/admin/products — Menambah produk baru
  • DELETE /api/admin/products/:id — Menghapus produk

Ketika Anda siap memfungsikan tabel MySQL, Anda cukup mengisi query database pada endpoint tersebut!
